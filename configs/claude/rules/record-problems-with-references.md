# 指摘と自分で見つけた問題は、参照リンクを添えて記録する

ユーザーから指摘を受けたとき、および自分で問題に気づいたときは、組み込みの Memory 指示に従って memory へ記録する。記録には、その作業を後から辿り直せる参照リンクを添える。

## 必須フロー

1. 契機は2つ。**指摘を受けたとき**と、**自分で問題を見つけたとき**。どちらも記録する。
2. 記録の形も置き場所も、組み込みの Memory 指示に従う。`metadata.type` を自分で選び直したり、memory の外へ書いたりしない。
3. 本文の末尾に `**参照:**` の行を足し、その作業の Issue・チケット・PR・チャットなどのリンクを並べる。

   ```markdown
   **参照:** toshiki670/dotfiles#738, PR #737
   ```

   - 実際にその作業で触れたものだけを書く。心当たりを推測で埋めない。
   - 紐づく参照が存在しないなら `なし`、存在したかもしれないが特定できないなら `不明` と書く。**行そのものを省かない** — 書き忘れと区別できなくなる。

## 補足

同じ論点の繰り返しかどうかの判定と、根本原因の調査は、記録の役目ではない。記録は材料を残すところまでで終わる。記録の以後の扱い（memory に残すか `~/Claude/feedback/` へ搬出するか）は `~/.claude/skills/memory-tidy/SKILL.md` が持つ。

## 例外

機密情報や、他では再現しない一時的な文脈は、そのまま memory へ書き写さない。
