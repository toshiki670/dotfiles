# 指摘と自分で見つけた問題は、参照リンクを添えて記録する

ユーザーから指摘を受けたとき、および自分で問題に気づいたときは、組み込みの Memory 指示に従って memory へ記録する。記録には、その作業を後から辿り直せる参照リンクを添える。

## 必須フロー

本文の末尾に `**参照:**` の行を足し、その作業の Issue・チケット・PR・チャットなどのリンクを並べる。

```markdown
**参照:** toshiki670/dotfiles#738, PR #737
```

- 実際にその作業で触れたものだけを書く。心当たりを推測で埋めない。
- 紐づく参照が存在しないなら `なし`、存在したかもしれないが特定できないなら `不明` と書く。**行そのものを省かない** — 書き忘れと区別できなくなる。

## `**How to apply:**` に書くこと

次に同じ状況へ出会ったときに、**自分が取る行動**を書く。「この決まりを適用先のファイル側へ書いておけ」という形にしない。そう書くと、その後に触ったファイルへ、その決まり自体を説明する文言が入る。

```markdown
**How to apply:** PR を出す前に、受け入れ条件と実際に書いた場所を1件ずつ対応させて確かめる。
```

## 例外

機密情報や、他では再現しない一時的な文脈は、そのまま memory へ書き写さない。
